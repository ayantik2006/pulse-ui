# Pulse UI

### Ship beautiful UIs faster without the headache

**Pulse UI** is a modern, customizable, and developer-first UI component library built for speed, flexibility, and clean design.

---

## 🚀 Why Pulse UI?

Most UI libraries either:
- Look good but are rigid  
- Or are flexible but ugly out of the box  

**Pulse UI fixes that.**

- 🎨 Beautiful by default  
- 🧩 Fully customizable  
- ⚡ High performance  
- 🛠️ Developer-first API  
- 🌙 Dark mode ready  
- 📦 Copy-paste friendly (no lock-in)

## 🤝 Contributing

Contributions are welcome and appreciated.

### Getting Started

1. Fork the repository  
2. Clone your fork  
   ```bash
   git clone https://github.com/your-username/pulse-ui.git
   cd pulse-ui
3. Install dependencies
    ```bash
   npm install
4. Start the development server
    ```bash
   npm run dev
   ```
   The website will be live on http://localhost:3000

5. You can take a look at the already decided components at http://localhost:3000/playground

---

### 🛠️ How to Contribute

1. Create a new branch
```bash 
git checkout -b feature/your-feature-name
```
2. Make your changes 
3. Test your changes properly

---

### ✅ Commit Guidelines
Use clear and meaningful commit messages:

- feat: add new button variant
- fix: resolve input focus bug
- docs: update README

---

### 🚀 Submitting Changes
1. Push your branch
```bash
git push origin feature/your-feature-name
```
2. Open a Pull Request
3. Describe what you changed and why
4. Wait for review

---

### 📌 Contribution Ideas

- Add new components ie - those not in the above list
- Improve accessibility
- Optimize performance
- Fix bugs
- Improve documentation

---

### ⚠️ Rules

- Keep components reusable
- Avoid unnecessary dependencies
- Maintain clean and readable code
- Don’t break existing components
